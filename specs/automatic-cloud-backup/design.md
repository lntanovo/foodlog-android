# Design

- WorkManager connected one-time work with a short edit debounce, exponential retry, periodic recovery and a startup catch-up. Only UID/login generation enter work input; no credentials or records.
- An application-scoped conflated runner also attempts the actual HTTPS endpoint on changes/login/connectivity. This handles networks where Android's external validation probe fails despite a reachable domestic CloudBase endpoint. It shares the same serialized engine with WorkManager; it does not replace durable scheduling or weaken TLS.
- A shared application-scoped coordinator serializes automatic jobs. Private atomic journal stores account association, known cloud head, canonical content fingerprint and a prepared immutable snapshot. Retry reuses the same backup UUID and bytes after a lost acknowledgement.
- Compare business content independent of export time, app version, local revision and collection ordering. Pristine means exactly the bundled foods plus no personal changes, including custom/favorite foods and profile.
- A PG RPC compares the known latest backup ID and inserts manifest metadata atomically under a per-owner transaction advisory lock. A trigger serializes legacy/manual inserts too and assigns monotonic server timestamps. A conflict leaves local data and historical cloud objects intact. No destructive migration, new paid service, or change to other applications.
- Restore only a verified full backup, with account-generation and local-revision guards under the repository mutation lock. Interrupted restore uses a durable intent containing the old revision: after restart, compare actual contents and re-evaluate instead of replaying blindly.
- Global status is visible on Today and Settings. Nonempty divergent installations expose cloud preview/restore or an explicit keep-local-and-back-up choice. Both are rechecked against the latest head.
- Tests: coalescing/deduplication, offline and process recovery, exact retry, pristine detection, automatic restore, late local edits, account switch, stale-head/CAS concurrency, malformed cloud files, protection backups, same-signature upgrade. Use synthetic test accounts/devices only.
